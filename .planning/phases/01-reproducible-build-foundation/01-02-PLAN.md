## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ISO/container bytes → decoder scratch | The complete untrusted graph is read-only preflighted first; only regular-file streams may then cross into an empty root-confined tree under strict no-link/type/path/resource limits. |
| Guest inspector → host staging | Audit data is untrusted until its ISO hash, schema, counts, and artifact references are independently validated. |
| Host staging → `dist/` | Only closed relative regular-file artifacts may cross into the last-known-good output. |
| Resource acquisition → outer cleanup owner | Every ephemeral process, listener, key, file, and overlay must be registered and disposed across all exits. |
