## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host → Docker daemon | A privileged local service receives bounded immutable inputs and returns untrusted staging/status data. |
| Resolver container → build container | Verified repository/aports bytes cross from networked resolution into a network-disabled build. |
| Adapter result → execution status | Only evidence-backed real process outcomes may become executed states. |
| Retained evidence → README claims | Public capability/size/status statements must match exact current artifact data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-P3-01 | Elevation of Privilege | Docker daemon/container | high | mitigate | Forbid socket, privileged mode, home/worktree/broad-state mounts; use named Linux volumes, read-only inputs, tmpfs secrets, and bounded export. |
| T-01-P3-02 | Tampering | Resolver-to-build packages | high | mitigate | Verify content-addressed snapshot and ResolvedBuildLock, run build container with no network and file-only repositories, and recheck before/after use. |
| T-01-P3-03 | Spoofing / Repudiation | Docker execution status | high | mitigate | Require live daemon/image/guest proof, real child result, and validated artifact evidence; fixtures and unavailable probes cannot emit executed-pass. |
| T-01-P3-04 | Information Disclosure | Docker diagnostics/mounts | high | mitigate | Persist allowlisted fields only, redact before disk, keep secret values out of argv/environment, and test the complete invocation record. |
| T-01-P3-05 | Tampering | Backend selection | medium | mitigate | Explicit Docker fails closed, explicit Qemu bypasses Docker, and Auto falls back only for enumerated sanitized unavailable results. |
| T-01-P3-06 | Repudiation | Documentation claims | medium | mitigate | Test README terms/commands against source and retained evidence; report actual bytes and explicit unverified Docker state. |
